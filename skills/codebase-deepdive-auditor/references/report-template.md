# Findings Report Template

Use this template when no report structure is provided.

## Findings

Order by severity (highest first).

For each finding, provide:

- Title
- Severity (`P0`/`P1`/`P2`/`P3`)
- Confidence (`high`/`medium`/`low`)
- Impact
- Reproduction or proof
- Expected behavior
- Actual behavior
- Code references (file + line)

## Open Questions / Assumptions

- State assumptions that influence confidence.
- State what evidence would upgrade confidence.

## Residual Risk

- Note areas not deeply tested.
- Note environment limitations that may hide additional issues.
